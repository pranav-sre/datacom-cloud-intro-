# Datacom Cloud Introduction — Forage Virtual Job Simulation

This repository documents my completion of the **Datacom Introduction to Cloud** 
virtual job simulation on Forage, where I stepped into the role of a Junior DevOps 
Engineer supporting a bank's migration to cloud infrastructure.

## What I did

- **Registered an application in Microsoft Entra ID (Azure AD)** to understand 
  how apps authenticate and get identities in a cloud environment (client IDs, 
  tenant IDs, and permission scopes).
- **Set up Git and GitHub** as version control tools, including cloning a 
  repository and managing changes from the command line.
- **Built a GitHub Actions workflow** (`.github/workflows/main.yml`) that 
  automatically triggers on every push to `main`, demonstrating a basic CI/CD 
  automation pipeline.

## Skills practiced

- Infrastructure as Code (IaC) concepts
- Cloud identity & access management (IAM) basics
- Git version control
- CI/CD automation with GitHub Actions
- YAML configuration

## Why this matters

Automating repetitive tasks and managing cloud resources securely are core 
responsibilities for DevOps engineers. This exercise gave me hands-on exposure 
to the tools (Azure, GitHub Actions) that underpin modern cloud infrastructure 
work.
